# Сравнение работы с Git: VS Code vs CLI

## Что удобно в VS Code:
1. Визуальный просмотр diff (наглядно видно добавленные и удаленные строки).
2. Разрешение merge-конфликтов кликом мыши (Accept Current / Incoming Change).
3. Просмотр авторов строк через расширение GitLens.

## Что удобнее в терминале:
1. Продвинутые манипуляции с историей: interactive rebase, cherry-pick, reset и reflog.
